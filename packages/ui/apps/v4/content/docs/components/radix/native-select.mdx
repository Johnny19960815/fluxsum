```tsx showLineNumbers
  NativeSelectOption,

```

```tsx showLineNumbers

```

## 组合结构

### 简单模式

选项直接放置在 `NativeSelect` 下（不使用 `NativeSelectOptGroup`）。

```text
NativeSelect
├── NativeSelectOption
├── NativeSelectOption
├── NativeSelectOption
└── NativeSelectOption
```

### 分组模式

使用 `NativeSelectOptGroup` 将选项组织成分类。

```text
NativeSelect
├── NativeSelectOptGroup
│   ├── NativeSelectOption
│   └── NativeSelectOption
└── NativeSelectOptGroup
    ├── NativeSelectOption
    └── NativeSelectOption
```

## Native Select 与 Select 的区别

- 使用 `NativeSelect` 获得原生浏览器行为、更好的性能或移动端优化的下拉菜单。
- 使用 `Select` 获得自定义样式、动画或复杂的交互效果。

## API 参考

### NativeSelect

包裹原生 HTML select 元素的主选择组件。

```tsx
<NativeSelect>
  <NativeSelectOption value="option1">Option 1</NativeSelectOption>
  <NativeSelectOption value="option2">Option 2</NativeSelectOption>
</NativeSelect>
```

### NativeSelectOption

表示选择器中的单个选项。

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `value`    | `string`  |         |
| `disabled` | `boolean` | `false` |

### NativeSelectOptGroup

将相关选项分组在一起，以便更好地组织。

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `label`    | `string`  |         |
| `disabled` | `boolean` | `false` |

```tsx
<NativeSelectOptGroup label="Fruits">
  <NativeSelectOption value="apple">Apple</NativeSelectOption>
  <NativeSelectOption value="banana">Banana</NativeSelectOption>
</NativeSelectOptGroup>
```
