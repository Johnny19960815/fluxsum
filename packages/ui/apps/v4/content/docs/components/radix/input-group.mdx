## 用法

```tsx showLineNumbers
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea,
} from "@/components/ui/input-group"
```

```tsx showLineNumbers
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

## 组合结构

使用以下组合结构来构建 `InputGroup`：

```text
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
└── InputGroupText
```

## 对齐

使用 `InputGroupAddon` 的 `align` 属性来设置附加元素相对于输入框的位置。

<Callout>
  为了正确管理焦点，`InputGroupAddon` 在 DOM 中应始终放置在
  `InputGroupInput` 或 `InputGroupTextarea` 之后。使用 `align` 属性来
  设置附加元素的视觉位置。
</Callout>

## API 参考

### InputGroup

包裹输入框和附加元素的主组件。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<InputGroup>
  <InputGroupInput />
  <InputGroupAddon />
</InputGroup>
```

### InputGroupAddon

在输入框旁边显示图标、文本、按钮或其他内容。

<Callout icon={<IconInfoCircle />} title="焦点导航">
  为了正确的焦点导航，`InputGroupAddon` 组件应放置在输入框之后。设置 `align` 属性来定位附加元素。
</Callout>

| Prop        | Type                                                             | Default          |
| ----------- | ---------------------------------------------------------------- | ---------------- |
| `align`     | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |
| `className` | `string`                                                         |                  |

```tsx
<InputGroupAddon align="inline-end">
  <SearchIcon />
</InputGroupAddon>
```

**对于 `<InputGroupInput />`，使用 `inline-start` 或 `inline-end` 对齐方式。对于 `<InputGroupTextarea />`，使用 `block-start` 或 `block-end` 对齐方式。**

`InputGroupAddon` 组件可以包含多个 `InputGroupButton` 组件和图标。

```tsx
<InputGroupAddon>
  <InputGroupButton>Button</InputGroupButton>
  <InputGroupButton>Button</InputGroupButton>
</InputGroupAddon>
```

### InputGroupButton

在输入组中显示按钮。

| Prop        | Type                                                                          | Default   |
| ----------- | ----------------------------------------------------------------------------- | --------- |
| `size`      | `"xs" \| "icon-xs" \| "sm" \| "icon-sm"`                                      | `"xs"`    |
| `variant`   | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"ghost"` |
| `className` | `string`                                                                      |           |

```tsx
<InputGroupButton>Button</InputGroupButton>
<InputGroupButton size="icon-xs" aria-label="Copy">
  <CopyIcon />
</InputGroupButton>
```

### InputGroupInput

构建输入组时替代 `<Input />` 的组件。该组件预设了输入组样式，并使用统一的 `data-slot="input-group-control"` 进行焦点状态处理。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

所有其他属性会透传给底层的 `<Input />` 组件。

```tsx
<InputGroup>
  <InputGroupInput placeholder="Enter text..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

### InputGroupTextarea

构建输入组时替代 `<Textarea />` 的组件。该组件预设了文本域组样式，并使用统一的 `data-slot="input-group-control"` 进行焦点状态处理。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

所有其他属性会透传给底层的 `<Textarea />` 组件。

```tsx
<InputGroup>
  <InputGroupTextarea placeholder="Enter message..." />
  <InputGroupAddon align="block-end">
    <InputGroupButton>Send</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```
