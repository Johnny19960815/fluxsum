`DirectionProvider` 组件用于设置应用的文本方向（`ltr` 或 `rtl`）。这对于支持从右到左的语言（如阿拉伯语、希伯来语和波斯语）至关重要。

以下是组件在 RTL 模式下的预览。使用语言选择器切换语言。要查看更多示例，请查看组件页面中的 RTL 部分。

## 用法

```tsx showLineNumbers
import { DirectionProvider } from "@/components/ui/direction"
```

```tsx showLineNumbers
<html dir="rtl">
  <body>
    <DirectionProvider direction="rtl">
      {/* Your app content */}
    </DirectionProvider>
  </body>
</html>
```

## useDirection

`useDirection` hook 用于获取应用的当前文本方向。

```tsx showLineNumbers
import { useDirection } from "@/components/ui/direction"

function MyComponent() {
  const direction = useDirection()
  return <div>Current direction: {direction}</div>
}
```
