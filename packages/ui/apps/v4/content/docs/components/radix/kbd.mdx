```tsx

```

```tsx

```

## 组合结构

使用以下组合结构来构建 `Kbd` 和 `KbdGroup`：

```text
Kbd
KbdGroup
├── Kbd
└── Kbd
```

## API 参考

### Kbd

使用 `Kbd` 组件来显示键盘按键。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup

使用 `KbdGroup` 组件将 `Kbd` 组件分组在一起。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
