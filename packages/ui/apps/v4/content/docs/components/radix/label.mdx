## 用法

```tsx
import { Label } from "@/components/ui/label"
```

```tsx
<Label htmlFor="email">Your email address</Label>
```

## 在 Field 中使用 Label

对于表单字段，请使用内置了 `FieldLabel`、`FieldDescription` 和 `FieldError` 组件的 [Field](/docs/components/radix/field) 组件。

```tsx
<Field>
  <FieldLabel htmlFor="email">Your email address</FieldLabel>
  <Input id="email" />
</Field>
```
