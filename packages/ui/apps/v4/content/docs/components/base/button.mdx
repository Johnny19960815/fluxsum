## 光标样式

Tailwind v4 将按钮组件的光标从 `cursor: pointer` [切换](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor)为 `cursor: default`。

如果你想保留 `cursor: pointer` 行为，请在 CSS 文件中添加以下代码：

```css showLineNumbers title="globals.css"
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

### 作为链接

你可以使用 `buttonVariants` 辅助函数使链接看起来像按钮。

**不要在链接中使用 `<Button render={<a />} nativeButton={false} />`。** Base UI 的 `Button` 组件始终应用 `role="button"`，这会覆盖 `<a>` 元素上的语义链接角色。请改用 `buttonVariants` 配合普通的 `<a>` 标签。

## API 参考

### Button

`Button` 组件是 `button` 元素的封装，添加了多种样式和功能。

| Prop      | Type                                                                                 | Default     |
| --------- | ------------------------------------------------------------------------------------ | ----------- |
| `variant` | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`        | `"default"` |
| `size`    | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |
