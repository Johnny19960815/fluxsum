## 用法

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
```

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## 组合结构

使用以下组合结构来构建 `Avatar`：

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

使用以下组合结构来构建 `AvatarGroup`：

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

## API 参考

### Avatar

`Avatar` 组件是包裹头像图片和后备内容的根组件。

| Prop        | Type                        | Default     |
| ----------- | --------------------------- | ----------- |
| `size`      | `"default" \| "sm" \| "lg"` | `"default"` |
| `className` | `string`                    | -           |

### AvatarImage

`AvatarImage` 组件用于显示头像图片。它接受所有 Base UI Avatar Image 的属性。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `src`       | `string` | -       |
| `alt`       | `string` | -       |
| `className` | `string` | -       |

### AvatarFallback

`AvatarFallback` 组件在图片加载失败时显示后备内容。它接受所有 Base UI Avatar Fallback 的属性。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarBadge

`AvatarBadge` 组件在头像上显示一个徽章指示器，通常定位在右下角。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroup

`AvatarGroup` 组件以重叠样式显示一组头像。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AvatarGroupCount

`AvatarGroupCount` 组件在头像组中显示数量指示器，通常用于显示额外的头像数量。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

更多关于 Base UI Avatar 属性的信息，请参阅 [Base UI 文档](https://base-ui.com/react/components/avatar#api-reference)。
