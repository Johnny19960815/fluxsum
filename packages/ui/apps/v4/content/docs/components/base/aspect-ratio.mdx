## API 参考

### AspectRatio

`AspectRatio` 组件以指定的宽高比显示内容。

| Prop        | Type     | Default | Required |
| ----------- | -------- | ------- | -------- |
| `ratio`     | `number` | -       | Yes      |
| `className` | `string` | -       | No       |

更多信息请参阅 [Base UI 文档](https://base-ui.com/react/components/aspect-ratio#api-reference)。
