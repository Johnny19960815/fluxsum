**FluxSum UI** 是基于 [shadcn/ui](https://ui.shadcn.com) 构建的企业级组件库，采用 Tailwind CSS v4 + Radix UI 原语，提供 68 个开箱即用的高质量组件。

## 特性

- **68 个组件** — 覆盖表单、数据展示、导航、反馈等常见场景
- **12 套主题** — 支持动态主题切换，适配不同品牌风格
- **移动端适配** — 全面兼容 iPad 和 H5 端，触摸优化
- **SSR 兼容** — 所有客户端组件均标注 `'use client'`
- **无障碍** — 基于 Radix UI 原语，内置 WAI-ARIA 支持

浏览 [组件文档](/docs/components) 查看所有可用组件。
