## APIs

### Separator

Built on Radix UI Separator. Accepts all `SeparatorPrimitive.Root` props.

| Property    | Description               | Type                         | Default        |
| ----------- | ------------------------- | ---------------------------- | -------------- |
| orientation | Direction                 | `'horizontal' \| 'vertical'` | `'horizontal'` |
| decorative  | Mark as decorative (aria) | `boolean`                    | `true`         |
