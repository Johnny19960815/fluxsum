## APIs

### ActionIconGroup

| Property | Description                      | Type                                              | Default     |
| -------- | -------------------------------- | ------------------------------------------------- | ----------- |
| size     | Size applied to all child icons  | `'xs' \| 'sm' \| 'default' \| 'md' \| 'lg'`     | `'default'` |
| variant  | Variant applied to all children  | `'default' \| 'outline' \| 'filled' \| 'ghost'`  | `'default'` |
