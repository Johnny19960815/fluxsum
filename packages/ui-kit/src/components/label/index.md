## APIs

### Label

Extends `LabelPrimitive.Root`. Accepts all HTML `<label>` attributes.

| Property | Description                        | Type     | Default |
| -------- | ---------------------------------- | -------- | ------- |
| htmlFor  | ID of the associated form control  | `string` | -       |
