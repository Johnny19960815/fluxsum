## APIs

### ScrollArea

Built on Radix UI ScrollArea. Accepts all `ScrollAreaPrimitive.Root` props.

| Property    | Description                  | Type                          | Default      |
| ----------- | ---------------------------- | ----------------------------- | ------------ |
| orientation | Scroll direction             | `'vertical' \| 'horizontal'`  | `'vertical'` |

Sub-components: `ScrollBar`
