## APIs

### Spinner

| Property | Description           | Type                                                       | Default     |
| -------- | --------------------- | ---------------------------------------------------------- | ----------- |
| size     | Size of the spinner   | `'xs' \| 'sm' \| 'default' \| 'lg' \| 'xl'`              | `'default'` |
| variant  | Color variant         | `'default' \| 'primary' \| 'secondary' \| 'destructive'`  | `'default'` |
