## APIs

### Empty

| Property    | Description                     | Type        | Default          |
| ----------- | ------------------------------- | ----------- | ---------------- |
| title       | Title text                      | `ReactNode` | `'No Data'`      |
| description | Description text                | `ReactNode` | -                |
| image       | Custom image or icon            | `ReactNode` | built-in icon    |
| action      | Action button or element        | `ReactNode` | -                |
