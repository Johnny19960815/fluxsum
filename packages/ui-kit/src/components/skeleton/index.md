## APIs

### Skeleton

| Property  | Description                    | Type                                            | Default     |
| --------- | ------------------------------ | ----------------------------------------------- | ----------- |
| variant   | Shape variant                  | `'default' \| 'circular' \| 'rectangular'`      | `'default'` |
| width     | Width of the skeleton          | `string \| number`                              | -           |
| height    | Height of the skeleton         | `string \| number`                              | -           |
| animated  | Enable pulse animation         | `boolean`                                       | `true`      |
| lines     | Number of text lines           | `number`                                        | -           |
